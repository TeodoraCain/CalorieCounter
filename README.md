🍏 EatWell – Calorie Counter (User App)

This repository contains the Android user application for EatWell, a fitness monitoring system designed to support a healthy and active lifestyle. The mobile app provides an intuitive interface to track calories, steps, and hydration, while integrating modern features such as AI-powered food recognition.

✨ Features

🔹 Add and manage daily food intake

🔹 Track steps and physical activity

🔹 Log daily water consumption

🔹 AI-based recognition of food from images using MobileNetV2

🔹 Firebase integration for real-time data storage and synchronization

🔹 Secure authentication via Firebase

🛠 Tech Stack

Language: Java (Android)

Architecture: Modular (DAO, adapters, services, utility classes, event management)

Machine Learning: MobileNetV2 (deep learning model trained on 10,900+ food images, 93% accuracy on test set)

Database & Auth: Firebase Realtime Database, Firebase Storage, Firebase Authentication

IDE: Android Studio
